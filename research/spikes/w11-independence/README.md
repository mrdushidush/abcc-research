# w11-independence — who plays the reviewer, and what a second opinion is actually for

Probes run 2026-08-22 for **W11 item 4 / W6 item 3 (gate independence)**. Findings **F270–F284** in
`research/W11-stages.md`.

Everything here is re-runnable from a clean checkout with no scratchpad path. The fixture is
`corpus/suites/k/tasks/finish_the_cancelled_status`, which is in this repository — 16 files,
~9.4k tokens, a real four-site bug, one correct decoy consumer (`jobs/dashboard.py`), a reference
solution, and a **shipped sham** that fixes the reported symptom and leaves three sites wrong. Its
verifier was gated at all three SPEC.md §9 points on 2026-08-17, so ground truth here is a program in
this repository rather than an opinion.

Held constants for every GPU probe, identical to W11 items 2 and 3: champion
`qwen3.6-35b-a3b-mtp@iq3_s`, loaded `-c 65536 --gpu max --parallel 1 -y`, nothing else resident,
LM Studio on `:1234`, temperature 0, `max_tokens` 8192, and the verdict schema item 3 shipped
(`../w11-artifacts/schemas/verdict.json`) verbatim — `rationale`, `defects`, `call`, in that order,
because F263 measured the order as causal.

## The regime

The Judge only matters where the deterministic half is green and the work is wrong (item 2 F251,
item 3 F266). So all four candidate changes here are **green on the acceptance criterion the ticket
implies**, and three of them are wrong:

| artifact | the change | criterion | four-consumer verifier |
|---|---|---|---|
| `sham` | `jobs/sla.py` only — the suite's shipped local wrong answer | pass | **FAIL** |
| `refsol` | all four consumers | pass | PASS |
| `comment` | `sla.py` fixed, the other three annotated with a comment claiming coverage | pass | **FAIL** |
| `disable` | the SLA symptom removed by making every terminal job unbreachable | pass | **FAIL** |


## The arms

Every arm sees the same thing except for one variable: the ticket verbatim, the repository tree,
`docs/status_lifecycle.md` (the specification the ticket names, which states all five semantics of
`cancelled`), `jobs/status.py`, the brief and the measurement set. **The information needed to catch
the sham is in every prompt**, which is what makes a `pass` inflation rather than ignorance.

- **A artifact** — fresh call, same weights, shown the unified diff.
- **B narration** — fresh call, same weights, shown *the author's own completion report* instead of
  the diff. v1's shape (F232). The report is generated by the model about its own change, so the
  story is the model's and not this probe's — see `narrations.json`.
- **C self-history** — the author's conversation continued: the builder head is still the system
  prompt, the diff is the assistant's own previous turn, the judge instruction is the next user turn.
  The shape single player produces if nobody thinks about it.
- **E both** — narration and diff together. Only has a question once B is known.
- **D swap** — arm A on a second model, after a load.

Scored two ways per call: the binary against ground truth, and the **recall of the three sites the
change actually left broken**, counted once over the `defects` array the pipeline carries and once
over the rationale as well — because a model that knows something and does not put it in the field
the gate reads has still failed the gate. `decoy` marks a call that named `jobs/dashboard.py`, the
consumer that is already correct.

## What came out

**1. The deciding axis is what the reviewer reads, not whose weights it is.** Same model, same
window, same temperature, same schema, same everything except the body of the prompt:

| arm | correct | caught (of 9 wrong) | explicit false pass | no verdict | false fail (of 3 right) | median wall | median completion |
|---|---|---|---|---|---|---|---|
| **A** the unified diff | **11/12** | **8** | 1 | 0 | 0/3 | 53.7 s | 3,533 |
| **E** report + diff | 9/12 | 6 | 3 | 0 | 0/3 | 38.2 s | 2,370 |
| **B** the author's report | 5/12 | 2 | 6 | 1 | 0/3 | 28.6 s | 1,739 |
| **C** the author's conversation | 4/12 | 1 | 3 | **5** | 0/3 | 75.2 s | 4,668 |
| **D** a second model, the diff | 7/12 | 7 | **0** | **5** | 0/3 stated, **3/3 operational** | 249.4 s | 7,131 |

```
            truth   A (diff)          E (report+diff)   B (report)        C (self)          D (27B)
sham        FAIL    fail fail fail    pass pass pass    pass pass pass    None fail None    fail fail None
refsol      PASS    pass pass pass    pass pass pass    pass pass pass    pass pass pass    None None None
comment     FAIL    fail fail fail    fail fail fail    pass pass pass    pass None pass    None fail fail
disable     FAIL    pass fail fail    fail fail fail    None fail fail    None None pass    fail fail fail
```

**2. 🚨 The author's completion report is subtractive, not merely useless.** Arm E is arm A's prompt
with the report pasted in front of the same diff, and it collapses to arm B on the `sham` — 3/3 → 0/3,
the K-suite's own shipped local wrong answer. The reports were generated by the model about its own
change before any judging (`narrations.json`), and the dangerous one is the *true* one: the sham's
report is accurate in every word and complete as an account of a job that is a quarter done.

**3. Self-review does not answer.** Five of arm C's twelve calls returned `finish_reason: length`,
`completion_tokens: 8192`, `reasoning_tokens: 8192` and an empty payload. When it does answer it
argues for its own work — naming all three unfixed modules in its rationale, emitting zero defects and
calling `pass`.

**4. 🚨 The second model is a better reader and an unusable Judge.** `qwen3.8-27b` never once approved
a wrong answer and named more broken sites than the champion — and returned no verdict at all on the
reference solution, 3 reps out of 3. Round trip measured at **26.3 s**, decode at **4.6×**.

**5. The criterion binds on 1 of 4 hunks** of the correct answer (`ablate.py`), measured with no model
in four criterion runs.

**6. 🚨 Of 35 generated acceptance criteria, 5 discriminate between the reference solution and three
wrong answers — and all 5 are defeated by one comment** carrying the tokens they grep for
(`criteria_vs_shams.py`, `grepbait.py`). 24 accept the sham, 24 accept the comment sham, 20 accept the
feature switched off. Zero reference anything that must *remain* true.

**7. Nothing false-failed the reference solution in any same-weights arm** — 0 of 9.

## Runner hygiene

Same host traps as item 3, same fixes: Git Bash named explicitly (`bash` on PATH here is WSL's), a
`python3` shim pointing at the interpreter that exists (`python3` on PATH is the Microsoft Store
shortcut), and a self-test in `build.py` that refuses to write results unless the runner can tell
exit 0 from exit 3, can run python, and reproduces the two ground truths the task file already
records — unfixed → FAIL, refsol → PASS.
